# 🎥 Vidéothèque Ghibli 

Bienvenue dans mon projet **Studio Ghibli** !  
Cette petite vidéothèque magique permet de :

- 🔎 Rechercher un film parmi tous les classiques Ghibli.
- ⭐ Trier les films par score (du meilleur au pire, et inversement).
- 👑 Afficher les **Top Films de la Semaine** avec des cartes stylées animées.
- 🎨 Profiter d’un design coloré, immersif et animé (oui, c’est classe).

## 🛠️ Technologies utilisées

- **HTML5**
- **Tailwind CSS** (pour le design responsive et animé)
- **JavaScript Vanilla**
- **[API Ghibli](https://ghibliapi.vercel.app/)** (pour les données)
